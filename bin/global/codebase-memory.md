## codebase-memory

- **Passo obrigatório antes do primeiro grep/Glob/Explore de uma tarefa de exploração de código** ("o que esse projeto faz?", onde fica X, quem chama Y, visão de arquitetura, impacto de mudança): verificar se o projeto está indexado. Fonte: a linha injetada pelo hook de SessionStart ou, na dúvida, chamar `list_projects` (carregar via `ToolSearch`, `select:mcp__codebase-memory__list_projects`) e comparar o `root_path` com o cwd (o projeto pode estar num worktree ou subdiretório do repositório).
- **Se estiver indexado, usar o grafo primeiro**: `get_architecture` para visão geral, `search_graph` para símbolos, `trace_path` para relações, `get_code_snippet` para fonte. `grep` só para literais ou lacunas de cobertura do grafo, e declarar na resposta qual dos dois foi usado e por quê.
- A regra vale para subagentes (Explore, investigador-*, executor-*): incluir no prompt delegado a instrução "usar o grafo codebase-memory antes de grep/Glob; grep só para literais ou lacunas de cobertura".
- Se houver hooks globais que reforçam essa regra (ex.: `cbm-hook`, com o modo `session` no SessionStart, que injeta a linha de projeto indexado, e o modo `pretool` no PreToolUse em Grep|Glob|Bash, que só avisa, nunca bloqueia, no máximo um aviso a cada 10 min por sessão), eles não substituem o passo acima.
- **Se o projeto não estiver indexado**, seguir o padrão (Read/Grep/Glob/Explore) e **sugerir a indexação uma vez**, via `AskUserQuestion` (opção "Indexar (Recommended)" primeiro, depois "Não indexar este projeto"). Antes de perguntar, checar a memória do projeto: se já existir a memória `codebase-memory-indexacao-recusada`, **não perguntar de novo** — só seguir o padrão. Nunca indexar sem a resposta afirmativa.
  - Se aceitar: `index_repository` (preferir `async: true` e acompanhar com `status: true` em repo grande) e usar o grafo na tarefa.
  - Se recusar: gravar a decisão com a Write tool em `~/.claude/projects/<projeto>/memory/codebase-memory-indexacao-recusada.md` (frontmatter `type: feedback`; corpo com **Why:** o usuário recusou indexar este projeto em `<data>` e **How to apply:** não sugerir indexação de novo, usar o padrão) e adicionar a linha de ponteiro no `MEMORY.md`. A decisão só é revista se o usuário pedir para indexar.
- Se o índice estiver defasado em relação à branch atual, avisar o usuário em vez de confiar cegamente nos resultados.
